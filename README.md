## Задание 1: Юнит-тесты

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Созданы юнит-тесты, покрывающие класс `Burger` (`tests/burger_test.py`):

- `set_buns` — установка и замена булочки;
- `add_ingredient` — добавление ингредиентов с сохранением порядка и дубликатов;
- `remove_ingredient` — удаление по индексу (граничные и отрицательные индексы), ошибки при неверном индексе;
- `move_ingredient` — перемещение по классам эквивалентности, ошибки при неверном индексе;
- `get_price` — расчёт стоимости (две булочки + ингредиенты, нулевые и дробные цены), текущее поведение без булочки;
- `get_receipt` — формат чека, приведение типа к нижнему регистру (отдельный тест), подстановка рассчитанной цены, текущее поведение без булочки.

В `.coveragerc` исключены модули (`bun.py`, `ingredient.py`, `database.py`, `ingredient_types.py`, `praktikum.py`), поэтому в `htmlcov` отображается покрытие именно класса `Burger`.

Процент покрытия 100% (отчет: `htmlcov/index.html`)

### Структура проекта

- `praktikum` - пакет, содержащий код программы
- `tests/burger_test.py` - юнит-тесты класса `Burger`
- `tests/conftest.py` - фикстуры и фабрики бургера, моков булочки и ингредиента
- `htmlcov/index.html` - HTML-отчёт

### Запуск автотестов

**Установка зависимостей**

```bash
pip install -r requirements.txt
```

**Запуск автотестов и создание HTML-отчета о покрытии**

```bash
pytest --cov=praktikum.burger --cov-report=html
```
